# SportsCenter — Roadmap

## Phase 0 — Content proof
- Create preferences fixture.
- Build one or more sport adapters.
- Build trusted source registry.
- Discover highlights and print `Wanted → Found → Missing`.
- Run 7–14 days and measure.

## Phase 1 — RN TV skeleton
- Installable APK.
- Home with fixture JSON.
- Excellent D-pad focus/navigation.
- Restore shelf focus on Back.

## Phase 2 — Real playback
- Five real trusted highlight cards.
- Play one video.
- Next/previous queue.
- Verify automatic advance between real highlights, as required by the TV UX and initial device milestone. Personalized Catch Me Up selection remains Phase 5.
- Back behavior.
- Persist progress.

## Phase 3 — One sport end-to-end
Choose a simple ecosystem (NFL/MLB/NBA/F1) and connect event data → preference → source → highlight → TV.

## Phase 4 — Library
Rolling 7-day Home, New, Earlier This Week, Continue Watching, watch state/history.

## Phase 5 — Catch Me Up
Quick/Standard/Everything; duration-aware balanced queue; autoplay.

## Phase 6 — Preferences
TV-friendly My Sports settings; teams/nations/rank threshold/event types; spoiler setting.

## Phase 7 — Add sports as adapters
NFL, MLB, NBA, F1, tennis, soccer, cricket; order can change based on user interest and validation.

## Phase 8 — Polish
Artwork, loading/error states, caching, performance, source badges, telemetry/debug diagnostics, accessibility.

## Explicitly deferred
Shows, movies, live TV, IPTV/EPG, TiviMate integration, social/news, betting/fantasy, generalized media center.
