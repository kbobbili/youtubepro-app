SportsCenter privacy policy

Last updated: 2026-10-03

SportsCenter is a personal tool used only by its owner. With the owner's permission, it uses the YouTube Data API to create and update private playlists on the owner's own YouTube account.

SportsCenter does not collect data from anyone else, does not sell or share data, and does not use data for advertising. The authorization token is stored only on the owner's own computer. Access can be revoked at any time at myaccount.google.com/permissions.

SportsCenter's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact: open an issue on GitHub.
